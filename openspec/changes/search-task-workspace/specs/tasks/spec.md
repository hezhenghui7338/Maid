# Spec Delta

## MODIFIED Requirements

### Requirement: 任务记录以原文为准

**来源**: PRD §10.1

一条任务 MUST 包含从该段识别出的任务说明、支撑判断的原文摘录、状态，以及是否由用户手改过状态。任务说明的事实来源 MUST 是原文。用户若要改变任务在说什么，MUST 修改原文并重新分析。任务面板 MUST NOT 改写任务说明。任务面板允许改的是状态和主题标签。任务面板 MUST 是与检索共用的整屏整理工作区里的段列表。写作屏 MUST NOT 在文档下方提供另一套改状态或改标签的控件。整理工作区 MUST NOT 以表格或独立任务卡片供用户改写任务正文。

#### Scenario: 任务面板不能改写说明

- **WHEN** 用户在整理工作区查看一条任务
- **THEN** 说明保持分析时的内容
- **AND** 这里没有改写任务说明的输入

#### Scenario: 在整理工作区改状态

- **WHEN** 用户在整理工作区把一条任务的状态从「待确认」改为「进行中」
- **THEN** 索引中该任务状态变为「进行中」，并标为用户手改
- **AND** 写作屏上不出现这条任务的状态下拉
