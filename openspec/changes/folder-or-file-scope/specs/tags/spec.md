# Spec Delta

## MODIFIED Requirements

### Requirement: 优先复用已有标签

**来源**: PRD §9

模型打新标签时，输入 MUST 附上当前选中范围内已经出现过的标签，并优先复用已有说法。选中范围外的标签 MUST NOT 因此被附上。未选中任何节点时，范围是整个存储根。

#### Scenario: 请求带上项目已有标签

- **WHEN** 选中文件夹里已有标签「上线」，另一文件夹里已有标签「复盘」，且新段正文会触发模型
- **THEN** 该段的请求内容包含「上线」
- **AND** 该段的请求内容不包含「复盘」
