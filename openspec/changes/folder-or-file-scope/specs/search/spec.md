# Spec Delta

## MODIFIED Requirements

### Requirement: 标签与状态查询

**来源**: PRD §12

用户 MUST 能按主题标签、按任务状态，或两者一起查询。查询范围 MUST 等于当前选中的节点：选中文件时 MUST 只命中这一篇；选中文件夹时 MUST 命中该文件夹及其嵌套的文件和子文件夹；未选中任何节点时 MUST 覆盖整个存储根。范围外的段 MUST NOT 出现。集中展示的 MUST 是段，不是从段里拆出的第二份任务正文。任务筛选只是多了一个状态条件。

#### Scenario: 标签与状态一起只命中同时满足的段

- **WHEN** 甲、乙带标签「上线」，甲的任务为「进行中」，乙的任务为「已完成」，且甲乙都在当前选中范围内，用户同时选择「上线」和「已完成」
- **THEN** 只有乙出现

#### Scenario: 选中文件时不命中其他文件

- **WHEN** 甲在选中的文件里且带标签「上线」，乙在另一篇文件里且同样带标签「上线」，用户按「上线」查询
- **THEN** 只有甲出现

#### Scenario: 选中文件夹时含嵌套文件

- **WHEN** 用户选中文件夹「调研」，其子文件夹里的乙带标签「上线」，同级另一文件夹里的丙也带标签「上线」，用户按「上线」查询
- **THEN** 乙出现
- **AND** 丙不出现
