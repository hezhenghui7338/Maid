# Proposal

## Why

规格把「项目」做成必须新建、必须切换的一层，文件只能挂在某个项目文件夹里。用户要的是常见文件编辑器的两层：文件夹和文件。管理范围跟选中节点走，不必再单独造一个项目。

## What Changes

- **BREAKING** 去掉「新建项目」和项目切换。Maid 固定存储根下直接是文件夹和 Markdown 文件。界面没有项目列表。
- **BREAKING** 管理范围等于当前选中的节点。选中文件时，搜索、标签和任务只覆盖这一篇；选中文件夹时，覆盖该文件夹及其嵌套的文件和子文件夹。未选中任何节点时，范围是整个存储根。
- 侧栏是可嵌套的文件夹与文件树。用户能新建文件夹、新建文件，并改名、删除选中的文件夹或文件。新建只填名称，落在当前选中的文件夹（选中的是文件时，落在该文件所在文件夹）。
- 文件仍只存 Markdown。索引仍在旁路，不写回正文。产品内仍然没有移动。仍然不能把本机任意外部文件夹当作存储根打开。
- 与 `openspec/specs/decisions` 无冲突。用户已确认：不改「非目标留在范围外」里「把用户自选的外部文件夹当作项目打开」。本变更不写这条拍板的 delta。

用户已确认：当前版本就改；存储仍是 Maid 固定位置；选中文件夹时范围含嵌套内容。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `editor`：「Maid 自管项目」改为存储根下一棵文件夹与文件树，不再新建或切换项目。「在项目中新建 Markdown」改为在选中位置新建文件，并增加新建文件夹。
- `files`：改名、删除扩展到文件夹；导入落在当前选中文件夹。仍不提供移动，导出仍只有正文。
- `search`：标签和任务状态查询改为只命中当前选中范围。
- `tags`：模型优先复用的已有标签，改为当前选中范围内已经出现过的标签。

## Impact

- 前端：`src/ui/App.tsx`、`src/ui/app.css`。顶栏项目下拉和「新建项目」去掉；侧栏从扁平路径列表改为树。`searchHits` 增加选中路径过滤。
- 本机存储：`src-tauri/src/projects.rs`、`src-tauri/src/lib.rs`。存储根即工作树；索引只放在存储根旁路目录。旧的「一个项目一个文件夹、各自一份 `.maid`」在打开时归并进根索引，文件 id 保留，路径加上原文件夹前缀。
- 进行中的 `file-sidebar-context-menu` 仍假定顶栏「新建项目」保留，且加号只新建文件。两处都落地时，以本变更为准：没有新建项目，且必须能新建文件夹和新建文件。
- 进行中的 `search-task-workspace` 把检索写成覆盖当前项目全部文档。两处都落地时，整理范围以本变更的选中节点为准，工作区形态仍用那一变更。
- 进行中的 `global-api-settings` 已把 API 设置移出项目。本变更不另写设置存放，也不再要求先选项目才能使用存储。
- 验收：`TDD.md` 的 ED-01、ED-04、ED-06、FL-01、FL-02、FL-05、SR-01 至 SR-04、TG-03。不改 `PRD.md`，不改 `RAW_PRD.md`，不改 `decisions`。
