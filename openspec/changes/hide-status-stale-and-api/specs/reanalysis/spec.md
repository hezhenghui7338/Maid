# Spec Delta

## MODIFIED Requirements

### Requirement: 过期不沿用旧高亮

**来源**: PRD §11.4

索引里的源码范围 MUST 只对应当时的正文。文档的更新时间晚于已分析段的处理时间时，界面 MUST NOT 显示「需要重新分析」。底栏在已打开文件时 MUST 仍显示该文件路径。过期期间 MUST NOT 用上次的段范围高亮当前正文。

#### Scenario: 已修改未分析时不再用旧范围高亮

- **WHEN** 文档已分析并能按某标签高亮一段，用户随后修改正文并保存，且不分析
- **THEN** 界面不出现「需要重新分析」
- **AND** 底栏仍显示该文件路径
- **AND** 该标签不再用上次的源码范围高亮当前正文
