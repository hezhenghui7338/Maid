# Spec Delta

## MODIFIED Requirements

### Requirement: 标签与状态查询

**来源**: PRD §12

用户 MUST 能从操作栏按主题标签、按任务状态，或两者一起查询。标签筛选项除「全部」外 MUST 固定为九个阶段，顺序为：立项计划、产品调研、产品设计、需求分析、技术设计、技术实现、缺陷管理、上线运营、项目复盘。筛选项 MUST NOT 随项目里出现过的说法增减或重排。集中展示的 MUST 是段，不是从段里拆出的第二份任务正文。任务筛选只是多了一个状态条件。

#### Scenario: 标签与状态一起只命中同时满足的段

- **WHEN** 甲、乙带标签「上线运营」，甲的任务为「进行中」，乙的任务为「已完成」，用户同时选择「上线运营」和「已完成」
- **THEN** 只有乙出现

#### Scenario: 筛选项固定为九个阶段

- **WHEN** 项目里只有一段带标签「上线」，用户打开标签筛选
- **THEN** 「全部」之外的选项依次是立项计划、产品调研、产品设计、需求分析、技术设计、技术实现、缺陷管理、上线运营、项目复盘
- **AND** 选项中没有「上线」
