# Proposal

## Why

标签检索现在跟着模型每次自造说法。同一类内容会出现不同名称，筛选下拉也不稳定，用户很难按研发阶段找回项目文档。

## What Changes

- 主题标签改为产品固定的九个阶段，顺序固定：立项计划、产品调研、产品设计、需求分析、技术设计、技术实现、缺陷管理、上线运营、项目复盘。
- 模型仍给已切好的段打标签、嗅探任务，但新写入的标签 MUST 是这九个阶段里的 0 到 2 个。模型自造的说法 MUST NOT 写入索引。
- 用户手改也只能在这九个阶段里增删，仍不超过 2 个。
- 操作栏的标签筛选固定列出这九个阶段，不再按项目里实际出现过的说法临时拼列表。
- **BREAKING**：已有索引里的自由说法不会自动改写成阶段。正文未变的段继续保留旧标签，直到用户手改或该段再次被模型更新。筛选里不再出现这些旧说法。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `tags`：把「不要求固定分类法」和「优先复用已有标签」改为只能使用固定阶段；模型请求带上这九个阶段，而不是项目里已经出现过的自由标签。不改 `decisions`：模型仍然只给程序切好的段打标签，标签仍在旁路索引，不写回 Markdown。
- `search`：标签筛选项改为这九个阶段及其固定顺序。命中仍是段，状态筛选和回跳方式不变。

## Impact

- 模型提示与输出校验：`src/core/model.ts`。非法阶段名按无效输出处理，不覆盖上一轮有效记录。
- 手改入口：`src/ui/App.tsx` 的新增标签从自由输入改为阶段选择。
- 检索下拉：不再使用 `collectTags` 收集到的自由说法。
- 验收：改 `TDD.md` 的 TG-03，并补阶段闭合与筛选顺序。回归 `bc-20260928-llm-freeform-tags`。
- 旧索引兼容：不迁移、不删除正文未变段上的旧标签。
