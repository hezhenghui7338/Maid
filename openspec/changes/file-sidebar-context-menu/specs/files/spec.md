# Spec Delta

## ADDED Requirements

### Requirement: 文件操作在右键菜单

导入、改名、删除和导出 MUST 只出现在文件栏的右键菜单里，MUST NOT 再作为文件栏文字按钮出现。在一份文件上右键时，菜单 MUST 含「导入」「改名」「删除」「导出」，且 MUST NOT 含「移动」。改名、删除、导出 MUST 作用在这次右键点中的文件。文件树为空时，在文件栏空白处右键 MUST 仍能「导入」。改名、删除、导入、导出的结果仍 MUST 分别遵守「改名保留索引」「删除清除索引」「导入只有正文」和「导出只有正文」。

#### Scenario: 右键文件出现四项且没有移动

- **WHEN** 用户在文件树的一份文件上右键
- **THEN** 菜单里有导入、改名、删除、导出
- **AND** 没有移动

#### Scenario: 空文件树仍可导入

- **WHEN** 当前项目的文件树为空，用户在文件栏空白处右键并选择导入
- **THEN** 用户可以把项目外的 Markdown 导入当前项目

#### Scenario: 导出的是右键点中的正文

- **WHEN** 用户右键一份未打开的文件并选择导出，同时另一份文件正在编辑且有未保存修改
- **THEN** 导出结果是被右键那份文件已保存的 Markdown 正文
- **AND** 其中不含另一份文件的未保存修改，也不含标签、任务、状态和文件 id
