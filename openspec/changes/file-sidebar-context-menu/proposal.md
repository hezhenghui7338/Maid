# Proposal

## Why

左侧文件栏顶部用一排文字按钮摆「新建、导入、改名、删除、导出」，入口挤、也分不清哪个作用在当前文件上。文件树应回到浏览本身：新建只留一个加号，其余文件操作藏进右键菜单。

## What Changes

- 去掉左侧文件栏顶部的「新建、导入、改名、删除、导出」文字按钮。
- 在左侧文件栏左下角放一个加号。有项目时点击只新建 Markdown；没有项目时不可用。顶栏「新建项目」不变。
- 在文件行上右键弹出「导入、改名、删除、导出」。改名、删除、导出作用在右键点中的那份文件，不限于当前打开的文件。
- 文件树为空时，在文件栏空白处右键仍可「导入」，否则空项目无法导入。
- 改名仍保留文件 id 与索引，删除仍清除索引，导入和导出仍只有正文。产品内仍然没有移动。

与 `openspec/specs/decisions` 无冲突：不改编辑器形态、不改索引、不改分析触发。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `editor`: 「在项目中新建 Markdown」的入口改为左侧文件栏左下角加号，不再使用文件栏文字按钮。
- `files`: 「改名保留索引」「删除清除索引」「导出只有正文」「导入只有正文」「不提供移动」的入口改为右键菜单；行为本身不变。

## Impact

- `src/ui/App.tsx`、`src/ui/app.css`：文件栏入口与右键菜单。
- `tests/stories.test.tsx`：现有测试点「新建」按钮；需改成点加号，右键菜单操作导入、改名、删除、导出。
- `TDD.md`：ED-04、FL-01 至 FL-05 的动作描述改为加号与右键。
