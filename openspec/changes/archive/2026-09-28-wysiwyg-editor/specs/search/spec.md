# Spec Delta

## MODIFIED Requirements

### Requirement: 原文高亮与邻段

**来源**: PRD §12

原文展示 MUST 在所见即所得文档中高亮命中的段。上下键 MUST 在命中段之间移动，并带出相邻段。高亮范围 MUST 对应该段在 Markdown 中的字符范围。

#### Scenario: 高亮命中并可移到邻段

- **WHEN** 按原文顺序有甲、乙、丙，甲和乙带标签「上线」，丙没有，用户按「上线」查询并在原文展示中按上、下键移动
- **THEN** 甲和乙在所见即所得文档中被高亮，丙不被高亮
- **AND** 移动时停在甲和乙，并带出各自相邻的段

### Requirement: 集中列表按原文顺序回跳

**来源**: PRD §12

集中展示 MUST 把命中段按原文顺序排成列表。点击一项 MUST 跳到该段在所见即所得文档中的对应位置。按状态筛选时，结果 MUST 只列出处于该状态的段，并且同样能跳回该文档。

#### Scenario: 列表顺序与点击回跳

- **WHEN** 用户打开标签「上线」的集中展示并点击乙，且甲在乙前
- **THEN** 列表顺序是甲然后乙
- **AND** 点击乙后，所见即所得文档定位到乙的范围
- **AND** 列表展示的是段，不是另写的一份任务正文

#### Scenario: 按进行中筛选后回跳

- **WHEN** 用户筛选「进行中」并点击结果，且只有甲处于该状态
- **THEN** 只有甲出现
- **AND** 点击后回到甲在所见即所得文档中的位置
