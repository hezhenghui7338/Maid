# Spec Delta

## ADDED Requirements

### Requirement: 全文再分析与按段再分析并存

用户 MUST 能对当前文档做全文再分析，也 MUST 能在按段展示中只再分析所点的一段。两次都 MUST 由用户手动触发。按段再分析 MUST NOT 在用户未点击时发生。

#### Scenario: 顶栏分析仍处理全文里已变化的段

- **WHEN** 文档有甲、乙两段都已分析，用户只修改甲并仍能与上一轮一对一，然后使用全文分析
- **THEN** 甲有一次模型请求
- **AND** 乙没有模型请求

### Requirement: 按段再分析只调用所选段

按段再分析 MUST 只把用户所点的那一段送给模型。同一文件中的其他段即使正文已变或已过期，也 MUST NOT 调用模型，已有标签、任务和手改标记 MUST 保持。所选段若与上一轮仍是一对一且正文未变，MUST 沿用索引中的标签和任务，MUST NOT 调用模型。所选段正文已变且仍一对一时，模型输入与写回 MUST 与全文再分析中的已变段相同。这次成功 MUST 更新所选段的处理时间。文件级的整篇已分析标记 MUST NOT 在其他段尚未按全文规则处理完时被写成已分析。

所选段的编辑若使它不再与上一轮一对一，这次按段再分析 MUST NOT 调用模型，也 MUST NOT 改写其他段，并 MUST 告知用户需改用全文分析。

#### Scenario: 只分析已改的甲，过期的乙不动

- **WHEN** 文档有甲、乙两段都已分析，用户把甲、乙都改成仍能各自一对一的新正文，然后在按段展示中只再分析甲
- **THEN** 只有甲有一次模型请求
- **AND** 乙没有模型请求
- **AND** 乙的标签、任务和手改标记与这次分析前相同

#### Scenario: 所选段正文未变时不调用模型

- **WHEN** 用户在按段展示中对一段正文未变、且仍与上一轮一对一的段执行再分析
- **THEN** 这段没有模型请求
- **AND** 标签和任务状态仍是分析前的结果

#### Scenario: 段边界已不再一对一时不调用模型

- **WHEN** 用户在按段展示中的编辑使所点的那一段被切成两段或与邻段合成一段，然后对该块执行再分析
- **THEN** 没有模型请求
- **AND** 其他段的标签和任务不变
- **AND** 界面告知需要改用全文分析
