# Spec Delta

## ADDED Requirements

### Requirement: 写作屏可在整篇与按段之间切换

写作屏 MUST 提供整篇展示与按段展示的切换。整篇展示 MUST 仍是一篇已渲染的文档。按段展示 MUST 把当前这篇文档按分段程序的结果逐段渲染。两种展示 MUST 都发生在写作屏上。界面 MUST NOT 并列源码区，MUST NOT 提供源码模式，也 MUST NOT 把按段展示做成源码与所见即所得的切换。

#### Scenario: 切到按段展示

- **WHEN** 用户在写作屏打开一篇含多个程序分段的 Markdown，并切换到按段展示
- **THEN** 写作屏按这些段逐段显示已渲染的原文
- **AND** 界面没有源码区
- **AND** 没有切换到源码模式的入口

#### Scenario: 切回整篇仍是同一篇渲染文档

- **WHEN** 用户从按段展示切回整篇展示
- **THEN** 写作屏显示同一篇已渲染的文档
- **AND** 两种展示编辑的是同一份草稿

### Requirement: 按段展示中可编辑段原文

在按段展示中，用户 MUST 能修改某一段的原文。修改 MUST 写回该文件的 Markdown。标签、任务和段时间 MUST NOT 因这次编辑写入 Markdown。

#### Scenario: 改一段后整篇和文件都带上这段文字

- **WHEN** 用户在按段展示中修改某一段的文字，再切回整篇展示并保存
- **THEN** 整篇展示中出现这段修改
- **AND** 该文件内容是包含这次修改的 Markdown
- **AND** 文件中不出现标签、状态或锚点
