# tags Specification

## Purpose

描述主题标签的数量、固定阶段和手改。主题标签是固定的研发阶段，用于按阶段检索。来源是原 PRD 第 9 节；固定阶段来自变更 fixed-stage-tags。

## Requirements

### Requirement: 每段最多两个主题标签

**来源**: PRD §9

每一段的主题标签 MUST 是 0 到 2 个。用户可以修改、删除、新增段的标签，但保存后仍 MUST NOT 超过 2 个。模型返回超过 2 个标签时，索引 MUST NOT 原样保存超限结果。

#### Scenario: 三个标签不会原样保存

- **WHEN** 模型对一段返回 3 个主题标签
- **THEN** 索引中该段主题标签不超过 2 个

#### Scenario: 手改不能加出第三个

- **WHEN** 一段已有 2 个标签时用户再新增 1 个
- **THEN** 这次新增不生效
- **AND** 段上仍是原来的 2 个

### Requirement: 优先复用已有标签

**来源**: PRD §9

模型打新标签时，输入 MUST 附上当前项目已经出现过的标签，并优先复用已有说法。

#### Scenario: 请求带上项目已有标签

- **WHEN** 项目里已有标签「上线」，且新段正文会触发模型
- **THEN** 该段的请求内容包含「上线」

### Requirement: 正文未变时手改标签保持

**来源**: PRD §9

用户手改过的标签 MUST 记在索引里。正文未变时，手改结果 MUST 保持不变，且这段 MUST NOT 再调用模型。

#### Scenario: 不改正文再次分析时标签仍是手改结果

- **WHEN** 用户改过一段的标签，且之后不改正文并再次分析
- **THEN** 标签与手改后一致
- **AND** 这段没有模型请求
