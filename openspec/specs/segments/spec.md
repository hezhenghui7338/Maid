# segments Specification

## Purpose

描述段如何由文档结构切出、段在索引中的身份，以及只有一对一才能继承上一轮标签和任务。来源是原 PRD 第 7.3、7.4 节和第 8 节。

## Requirements

### Requirement: 段索引字段

**来源**: PRD §7.3、§8

每一段 MUST 在索引中具有所属文档、源码范围、创建时间、更新时间、处理时间、内容哈希，以及由文件 id、标题路径和段内序号组成的身份。段身份 MUST 只存在于索引中，MUST NOT 写进原文。更新时间晚于处理时间时，这段正文相对上次分析已经变化，可以进入下一轮分析。

#### Scenario: 分析后段记录字段齐全

- **WHEN** 用户完成一次分析
- **THEN** 每段索引含所属文件 id、源码范围、创建时间、更新时间、处理时间和内容哈希
- **AND** 身份由文件 id、标题路径和段内序号组成
- **AND** 文件 id 不在 Markdown 里

### Requirement: 标题构成第一层边界

**来源**: PRD §8

分段 MUST 可重复。同一次正文、同一套规则，MUST 得到同一组段边界。系统 MUST 先按 Markdown 标题层级把文档切成章节。标题本身携带的结构 MUST 作为第一层段边界。段边界 MUST NOT 落在标题句子中间。

#### Scenario: 标题切开章节

- **WHEN** 文档含「立项」和其下「范围」两级标题
- **THEN** 至少切出「立项」和「立项 / 范围」两个章节
- **AND** 段边界落在标题上

### Requirement: 过长章节在块边界再切

**来源**: PRD §8

章节正文过长时，系统 MUST 只在块边界再切。块包括段落、列表项、代码块、表格和引用。长度上限 MUST 是可调整参数，规则本身 MUST NOT 依赖某个固定数字。一段应当短到能打出不超过 2 个主题标签，并至多包含一条任务。连续的引用行 MUST NOT 从行中间切开。

#### Scenario: 两个段落从空行切开

- **WHEN** 长度上限小于两个段落连在一起的长度，且大于单个段落，同一标题下有两个独立段落
- **THEN** 两段分开
- **AND** 切开位置在段落之间
- **AND** 段内序号在该标题下递增

#### Scenario: 引用整块保留

- **WHEN** 一个 blockquote 有多行引用，中间没有空开成另一个块
- **THEN** 这段引用不被从行中间切开

### Requirement: 代码块和表格保持整块

**来源**: PRD §8

代码块和表格 MUST 保持整块。系统 MUST NOT 从代码块或表格中间切开，即使它们长于长度上限。

#### Scenario: 长代码块不被切开

- **WHEN** 围栏代码块长于长度上限，且块内有多行
- **THEN** 代码块整个属于一段
- **AND** 没有一段只含代码块的前半或后半

#### Scenario: 长表格不被切开

- **WHEN** 一个含多行的 Markdown 表格长于长度上限
- **THEN** 表格整个属于一段
- **AND** 没有一段只含表头或其中几行

### Requirement: 清单按列表项切开

**来源**: PRD §7.4、§8

一段正文里如果有多条可执行事项，系统 MUST 靠分段拆开，而不是在同一段上挂多条任务。任务清单 MUST 优先按列表项切段，使一条可执行事项对应一段。

#### Scenario: 两个列表项各成一段

- **WHEN** 一个标题下有两个列表项
- **THEN** 两个列表项各成一段
- **AND** 段内正文分别只含对应的一项

### Requirement: 同输入得到同一分段

**来源**: PRD §8

对同一份正文调用分段程序两遍时，边界、标题路径、段内序号和内容哈希 MUST 一致，并且 MUST NOT 发出模型请求。

#### Scenario: 两遍分段结果相同

- **WHEN** 对同一份正文分别分段两次
- **THEN** 边界、标题路径、段内序号和内容哈希两次相同
- **AND** 没有模型请求

### Requirement: 一对一才继承旧标签和任务

**来源**: PRD §8

只有上一轮与这一轮能一对一对应的段，才 MUST 继承旧标签和旧任务。一段被切成多段，或多段合成一段时，旧任务 MUST NOT 挂到其中任何一段。

#### Scenario: 切开后新段不自动带着旧任务

- **WHEN** 一段已有任务的正文在下一轮被切成两段
- **THEN** 切开后的两段都不自动带着这条旧任务
